# Detector Calibration Pipeline — Synthetic Waveform Analysis

Python pipeline that simulates, processes and validates particle-detector waveform data, extracting calibration-relevant features (peak amplitude, integrated charge, signal detection) and generating an automated calibration QA report.

This project mirrors the type of data pipeline I build for detector/laser-instrumentation calibration in my PhD research (LIP / CERN, PT-CERN fellowship), applied to international neutrino experiments (DUNE, SBND, ProtoDUNE). All data here is fully synthetic — no real detector geometry, calibration constants, or experiment data is used.

## Why this project

A large part of my research work involves processing thousands of high-volume waveform samples generated by detector and laser instrumentation, extracting physically meaningful features, and flagging anomalies for calibration teams — all before the underlying analysis pipeline can move forward. Since real experiment data and detector configurations are confidential to the collaboration, this repository recreates the same data-processing and QA pattern with synthetic signals.

## Problem

Detector channels (e.g. photomultiplier tubes) continuously produce waveform data, only a fraction of which contains a real physical signal — the rest is noise. Calibration teams need to reliably separate signal from noise, extract quantitative features per channel, and catch hardware anomalies (e.g. a channel firing too often or too rarely) without manual waveform-by-waveform inspection.

## Architecture

```
[Synthetic Waveform Generator]
   32 channels x 5,000 events, bi-exponential pulse model + Gaussian noise
                    |
                    v
        [Raw Layer: Parquet waveform arrays]
                    |
                    v
      [Signal Processing / Feature Extraction]
      - peak amplitude, peak time, integrated charge
      - baseline RMS
      - signal/noise classification (threshold-based)
                    |
                    v
        [Processed Layer: per-channel features]
                    |
                    v
        [Calibration QA Report]
        - per-channel detection rate
        - anomaly flagging (channels outside expected range)
                    |
                    v
        [calibration_summary.csv]
```

## Tech Stack

- **Simulation**: NumPy (bi-exponential pulse model, Gaussian noise)
- **Processing**: Pandas (feature extraction, aggregation)
- **Storage**: Parquet (raw/processed layers), CSV (final report)
- **Validation**: Precision/recall against synthetic ground truth
- **Language**: Python 3.11

## How to Run

1. Install dependencies: `pip install -r requirements.txt`
2. Generate synthetic waveform data: `python simulation/detector_producer.py`
3. Extract features and validate signal detection: `python processing/signal_processing.py`
4. Generate the calibration QA report: `python reporting/calibration_report.py`

## Result

On a simulated batch of 5,000 events across 32 channels (160,000 channel-waveforms), the pipeline extracts per-waveform features in seconds and validates signal detection against synthetic ground truth with precision and recall typically above 0.9, then produces a per-channel calibration summary flagging any channel with an anomalous detection rate.
